## 上传前必须检查

1. `.env`、真实 API Key、个人历史、数据库和报告都不要提交。`.env.example` 只能放占位符。
2. 核实参考项目许可证。当前本地副本只有 README 的 MIT 声明，未发现 LICENSE；保留来源说明并进一步确认授权。
3. 确認仓库中没有硬编码的用户名、私人问题、令牌或编辑器本机配置。
4. 检查 git 暂存区；`.gitignore` 不会自动清除已经跟踪或写入历史的秘密。如果泄漏，首先撤销/轮换密钥，再处理 Git 历史。
5. 运行语法检查和不收费的本地测试。需要真实 API 的演示由你自行决定是否运行。

在项目根目录执行以下只读检查：

```powershell
git status --short
git diff --cached --stat
git diff --cached --name-only
```

确认内容后再提交。本文不自动创建仓库、不执行 push，也不替你选择公开或私有。
